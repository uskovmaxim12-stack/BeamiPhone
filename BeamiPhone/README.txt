BeamiPhone 1.2  -  by wserf
iPhone-style phone overlay for BeamNG.drive

INSTALL
  1. Remove the old "BeamPhone" mod (zip or unpacked folder) first, so the two do not clash.
  2. Put BeamiPhone.zip into  Documents/BeamNG.drive/mods/  and enable it in the Mod Manager.
  3. In game: Options > Controls: the "BeamiPhone: toggle phone" action is bound to F3.
     Then add the "BeamiPhone" UI app to your HUD layout (UI Apps).

MUSIC
  Put .mp3 / .ogg / .wav files into  Documents/BeamNG.drive/beamiphone/music/
  (covers: song.jpg next to song.mp3, or one cover.jpg per folder).
  The old folder  beamphone/music/  is still scanned, nothing needs to be moved.

SETTINGS / NOTES
  Saved in  Documents/BeamNG.drive/settings/beamiphone/  (old settings are picked up automatically).
